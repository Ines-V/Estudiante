4. ESTUDIANTE
Crea la clase Estudiante con los atributos privados nombre, edad y nota. 

•	Constructor, getters, setters, toString() y mostrarInformacion(). 

•	La nota debe estar entre 0 y 10, ambos incluidos. La edad no puede ser negativa. 

•	Añade una variable estática privada totalEstudiantes y un método estático getTotalEstudiantes(). El contador solo aumenta cuando el estudiante se crea correctamente (incrementa al final del constructor). 

Clase de prueba: TestEstudiante. Prueba las notas 0, 10, -1 y 10.5. Crea tres estudiantes válidos, intenta crear uno con la nota -1 y muestra el total: debe ser 3.
